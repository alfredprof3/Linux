# Vimium for Librewolf

Browser extension which provides keyboard shortcuts for navigation and control in the spirit of the Vim editor.

|   Keybinding    | Action                                           |
| :-------------: | :----------------------------------------------- |
|       `j`       | Scroll down                                      |
|       `k`       | Scroll up                                        |
|      `gg`       | Scroll to the top of the page                    |
|   `Shift` `G`   | Scroll to the bottom of the page                 |
|       `d`       | Scroll a half page down                          |
|       `u`       | Scroll a half page up                            |
|       `h`       | Scroll left                                      |
|       `l`       | Scroll right                                     |
|       `r`       | Reload                                           |
|      `yy`       | Copy the current URL to the clipboard            |
|       `p`       | Open the clipboard's URL in the current tab      |
|   `Shift` `P`   | Open the clipboard's URL in a new tab            |
|       `i`       | Enter insert mode                                |
|       `v`       | Enter visual mode                                |
|      `gi`       | Focus the first text input on the page           |
|       `f`       | Open a link in the current tab                   |
|   `Shift` `F`   | Open a link in a new tab                         |
|      `gf`       | Select the next frame on the page                |
| `g` `Shift` `F` | Select the page's main/top frame                 |
|       `/`       | Enter find mode                                  |
|       `n`       | Go forward to the next find match                |
|   `Shift` `N`   | Go backward to the previous find match           |
|       `o`       | Open URL, bookmark or history entry              |
|   `Shift` `O`   | Open URL, bookmark or history entry in a new tab |
|       `b`       | Open a bookmark                                  |
|   `Shift` `B`   | Open a bookmark in a new tab                     |
|   `Shift` `T`   | Search through your open tabs                    |
|   `Shift` `H`   | Go back in history                               |
|   `Shift` `L`   | Go forward in history                            |
|       `t`       | Create new tab                                   |
|   `Shift` `J`   | Go one tab left                                  |
|   `Shift` `K`   | Go one tab right                                 |
|      `g0`       | Go to the first tab                              |
| `g` `Shift` `$` | Go to the last tab                               |
|      `yt`       | Duplicate current tab                            |
|       `x`       | Close current tab                                |
|   `Shift` `X`   | Restore closed tab                               |
|       `?`       | Help                                             |
