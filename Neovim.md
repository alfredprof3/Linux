# Neovim commands

Enter in Terminal-mode
:terminal

Leave Terminal-mode
<C-\><C-N>

Leave Terminal-mode in macOS with a macOS keyboard layout, type:
`⌃ ⌥ ?` + `⌃ N`

Leave Terminal-mode in PC with a macOS keyboard layout, type:
`⌃ ⌘ ?` + `⌃ N`

Leave Terminal-mode in PC, type:
`Ctrl AltGr ?` + `Ctrl N`
